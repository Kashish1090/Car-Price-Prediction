# Car-Price-Prediction
This project aims to build a machine learning model that can accurately predict the selling price of a car based on various features such as its brand, model, manufacturing year, fuel type, transmission, mileage, engine capacity, and more.

📌 Objective
To develop a predictive model that helps individuals and businesses estimate the fair market value of a used car, which can aid in both buying and selling decisions.

🧠 Technologies & Tools Used
Python (Pandas, NumPy, Matplotlib, Seaborn)
Scikit-learn (Linear Regression, Random Forest)
Jupyter Notebook
Power BI (for dashboard/report visualization)

📊 Dataset
The dataset includes details of used cars such as:

Car Name
Year of Purchase
Selling Price
Present Price
Kms Driven
Fuel Type
Seller Type
Transmission
Owner

Data Cleaning & Preprocessing

Handling missing values

Feature selection

Exploratory Data Analysis (EDA)

Visualizing price trends

Model Building

Implemented Linear Regression and Random Forest
